# `corco-installer` — the client bootstrap

Guidance for any agent working in this repository.

## What this repo is

The bootstrap a customer runs in Google Cloud Shell: `setup.sh` onboards and `teardown.sh`
removes, and `TUTORIAL.md` and `TEARDOWN.md` are the Cloud Shell tutorials that walk the
customer through each. The platform itself is built and released from `corco-platform`.
This is the estate's one public repository (`corcoai/corco-installer`).

## What customers run: the `release` branch

- **Both Cloud Shell buttons on `setup.corco.ai`, setup and teardown, clone this
  repository's `release` branch.** The branch is `INSTALLER_BRANCH` in
  `corco-platform/deployment/functions/setup-landing/main.py`; its default is `release`, and
  the deployed function sets no override. Live since 2026-09-18 on revision
  `setup-landing-00033-cuy`.
- **`main` is not live.** A push or merge to `main` reaches no customer.
- **Moving `release` is the customer release**: the commit it points at is what the next
  customer clones. That makes it a Corco deploy, so it stays a gated deploy under the
  existing rule: every Corco deploy needs a fresh named go, each time.
- `release` was created on 2026-09-18 at `79eaffd`, the commit `main` held when the setup
  page was switched, so the switch changed nothing customers run.
